# Project map

This guide describes the active application folders. Generated files, local credentials, and installed packages are not source code.

## Repository root

- `README.md` explains installation and how to run the app.
- `requirements.txt` lists the Python backend dependencies.
- `.gitignore` contains the repository-wide ignore rules.
- `pyproject.toml` contains Python formatter and lint settings.
- `.prettierrc.json` and `.prettierignore` contain frontend formatting rules.
- `backend/` contains the Python API.
- `frontend/` contains the React application.
- `screenshots/` contains images embedded in the README.
- `docs/` contains project and development notes.

## Backend request flow

1. A file in `backend/app/routers/` receives an HTTP or WebSocket request.
2. `backend/app/core/` provides shared authentication and connection helpers.
3. `backend/app/schemas/` validates incoming and outgoing data.
4. `backend/app/services/` enforces project and task rules and reads or writes the database.
5. `backend/app/models/` defines database tables and their relationships.

`backend/app/main.py` creates the FastAPI app and registers its routers. `backend/app/config.py` reads environment settings; `backend/app/database.py` configures database connections and sessions.

## Frontend request flow

- `frontend/src/pages/` composes full screens and route-level behavior.
- `frontend/src/components/` contains reusable UI elements such as task and project cards.
- `frontend/src/api/` centralizes API calls and the Axios connection.
- `frontend/src/context/` shares authentication and WebSocket state across screens.
- `frontend/src/App.jsx` defines routes and protected screens.

Keep API requests in `src/api`, reusable display or input elements in `src/components`, and screen orchestration in `src/pages`.

## Local-only and generated folders

- `.venv/` is the repository’s Python environment.
- `frontend/node_modules/` contains installed JavaScript packages.
- `frontend/build/` is generated production output.
- `__pycache__/` and `*.pyc` are generated by Python.
- `.env` files contain local configuration and credentials.

Generated folders and local credentials should not be committed. They can be recreated or supplied locally and are excluded by the root `.gitignore`.

## Formatting configuration

- `.editorconfig` sets line endings, final newlines, and indentation for the whole repository.
- `pyproject.toml` records the Black and Ruff Python style settings.
The formatter programs are optional developer tools and are not runtime dependencies.
